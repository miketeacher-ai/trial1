# IELTS Academic Grammar: Mastering Tense and Aspect Control

This repository contains a comprehensive IELTS Academic grammar lesson pack designed to help students bridge the gap between Band 5 and Band 7+.

## Overview

The lesson focus is on **Tense and Aspect Control**, which is critical for achieving a Band 7+ in IELTS Writing and Speaking, and for accurately interpreting meaning in IELTS Reading.

### Key Components

- **Core Timeline Explanation**: A quick map for recognition and production.
- **IELTS Tense Function Map**: Specific uses for each tense across all four IELTS modules.
- **Band 5 to Band 7 Upgrades**: Examples of how to transform basic sentences into academic ones.
- **Mini-Lessons and Tests**: Targeted practice for each major tense.
- **Academic Reading Focus**: Passages and analysis tasks to improve reading comprehension through grammar.
- **Task-Specific Practice**: Exercises for Writing Task 1, Writing Task 2, and Speaking.
- **Common Tense Mistake Bank**: A diagnostic tool for avoiding frequent errors.
- **Diagnostic Test**: 130+ questions to verify mastery.

## How to Use

1. Open `index.html` in any modern web browser.
2. Use the **Table of Contents** to navigate between sections.
3. Use the **Open/Close answers** buttons to reveal or hide the keys for practice exercises.
4. Use the **Print / Save PDF** button to generate a clean, printable version of the lesson pack.

## Target Audience

- **Students**: Aiming for IELTS Academic Band 7 or higher.
- **Teachers**: Looking for a complete, structured curriculum for teaching tense control.
